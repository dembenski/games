# 8bitvapor Games Hub

The home of **Michael Dembenski & Bit** — Horizon Worlds games, web games, and the SHARE MY GAME directory.

- **Live site:** https://dembenski.github.io/games/
- **SHARE MY GAME directory:** https://dembenski.github.io/games/all-games.html — 1,092 Horizon Worlds games found by the community watch, with descriptions, cover art, and videos.

## What's here

- The **Games Hub** (`index.html`) — Michael's own Horizon Worlds games, each with a Play in Horizon link.
- **SHARE MY GAME** (`all-games.html`) — the mega directory of every game the watch has found.
- **VoxelHaven** (`voxelhaven/`) — AR Minecraft-style voxel builder with hand tracking.
- **CodePen games** (`codepen-*.html`, `club-vapor-game.html`) — web games rescued from CodePen.
- **Eatmon family research** (`eatmons-black-loyalist-research.html`, `eatmon-military-service.html`) — Black Loyalist and military service research.
